# 📊 Power BI Data Analysis Project

## 🧾 Project Title
**Superstore Sales Performance Dashboard**

---

## 📘 Description
This Power BI project was created as part of my internship at **ElevvoTech**.  
It focuses on analyzing **Super Store Slaes** to generate insights and data-driven decisions.

---

## 🔍 Project Overview
- Cleaned and transformed raw data using **Power Query**.  
- Built interactive visualizations and key performance indicators (KPIs).  
- Designed an insightful dashboard highlighting major trends and metrics.  
- Published the report on **Power BI Service** for easy access and sharing.

## 🧠 Key Insights
- The **West region** recorded the highest overall sales, contributing significantly to total revenue.  
- **Technology** category products generated the most profit, while **Furniture** showed lower margins.  
- **California** and **New York** were the top-performing states in both sales and profit.  
- **Standard class shipping** had the highest number of orders but with lower average profit per order.  
- **November and December** showed peak sales activity, indicating strong year-end demand.  
- High discounts were strongly correlated with **reduced profit margins**, especially in the furniture segment.  
- **Corporate customers** accounted for the largest share of revenue among customer segments.
